# Contributing

Thanks for taking an interest in Simple Notes.

## Build

You need macOS 14+ and Xcode or Command Line Tools.

```bash
git clone https://github.com/MoomenALdahdouh/SimpleNotes.git
cd SimpleNotes
./scripts/test.sh
./scripts/build.sh
open "dist/Simple Notes.app"
```

Keep changes small. Version 1 stays a local text editor: no cloud, accounts, or network features.
